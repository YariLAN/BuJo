# BJ-5 HabitLog: отметка выполнения привычки + статистика + напоминания

## Контекст

В текущей реализации пользователь может создать привычку через `/habits` → «➕ Добавить» и увидеть её в списке. Однако нет возможности отметить выполнение привычки за день — `HabitLog` (доменная сущность и таблица в БД существуют, но не задействованы). Отсутствует статистика (streak, процент выполнения), и нет автоматических напоминаний.

Пользователь хочет:
- Отмечать выполнение привычек за сегодня и предыдущие дни прямо из списка привычек
- Видеть прогресс: streak (дни подряд), процент выполнения за месяц
- Получать вечерние push-напоминания с возможностью отметить привычку не заходя в `/habits`

## Цели

- Пользователь открывает `/habits`, видит список привычек с номерами — пишет номер привычки текстом
- Бот показывает подменю привычки с inline-кнопками: `[✅ Отметить] [📅 Другой период] [❌ Пропустить]`
- Нажатие `✅` сохраняет `HabitLog` за сегодня
- Нажатие `❌` создаёт пропуск за сегодня
- В разделе привычек есть отдельная кнопка `📊 Статистика` — открывает выбор привычки и показывает её статистику
- Статистика показывает streak (дни подряд), процент за месяц, календарь отметок
- В установленное время (вечернее, из `User.ReminderEveningTime`) бот присылает сообщение с напоминанием отметить привычки
- Кнопка в напоминании → отметка без захода в `/habits`

>
> **Пользователь:** нажимает `☐ 🧘 Медитация`
> **Бот:** (редактирует) меняет на `☑ 🧘 Медитация`
>
> **Пользователь:** нажимает `✅ Подтвердить`
> **Бот:** (редактирует то же сообщение)

> Читать книгу — пропущено ❌
>
> [✅ Подтвердить]" → кнопка заменяется на "✅ Готово" (disabled / неактивна)"

## Out of scope

- CRUD привычек (создание/редактирование/архивация) — уже есть, не трогаем
- Утренние напоминания (`ReminderMorningTime`) — только вечерние
- Веб-дашборд — API контракты закладываем, UI не входит
- Статистика за произвольный вводимый период — только предустановленные: сегодня, неделя, месяц
- Редактирование/удаление `HabitLog` — только создание отметки
- Автоматический пропуск выходных в streak — streak календарный

## Требования

### Функциональные

1. **Список привычек:**
   - Список выводится обычным текстом с нумерацией (без inline-кнопок на каждую привычку)
   - Пользователь пишет номер привычки → бот переходит в подменю привычки
   - Отдельные inline-кнопки только для действий: `➕ Добавить`, `📊 Статистика`, `🏠 Назад`
   - Выбор привычки по номеру — через `PendingAction.AwaitingHabitSelect`

2. **Подменю привычки:**
   - `[✅ Отметить]` — отметка за сегодня (создаёт `HabitLog` с `IsCompleted = true`)
   - `[📅 Другой период]` — выбор даты: вчера, позавчера, указать вручную
   - `[❌ Пропустить]` — создаёт `HabitLog` с `IsCompleted = false` за сегодня
   - Если отметка за сегодня уже существует — кнопка `✅` меняется на `✅ (уже отмечено)`

3. **Отметка:**
   - Пользователь может отметить привычку за сегодня, вчера, позавчера или указать произвольную дату
   - Отметка создаёт запись `HabitLog`
   - Если отметка за дату уже существует — upsert (обновить `IsCompleted`)
   - При `📅 Указать дату` — ожидание текстового ввода в формате `ДД.ММ.ГГГГ` (новый `PendingAction`)

4. **Статистика:**
   - Вынесена в отдельную кнопку в разделе привычек
   - После нажатия — выбор привычки из списка
   - **Streak:** количество последовательных календарных дней с `IsCompleted = true` подряд до сегодня (или до последнего дня с отметкой)
   - **За месяц:** процент дней с `IsCompleted = true` / общее количество дней в месяце
   - **Календарь:** последние 7 дней с цветовой индикацией ✅/❌

5. **Напоминания (чек-лист):**
   - В `User.ReminderEveningTime` (если установлено) бот отправляет сообщение-чек-лист со списком неотмеченных на сегодня привычек
   - Каждая привычка — toggle-кнопка: `☐` (не отмечено) ↔ `☑` (отмечено)
   - Нажатие на привычку переключает её состояние в том же сообщении (редактирование)
   - Кнопка `✅ Подтвердить` — фиксирует выбор: все `☑` → `HabitLog` с `IsCompleted = true`; все `☐` → `HabitLog` с `IsCompleted = false`
   - Если пользователь нажал `✅ Подтвердить` ничего не выбрав — все привычки считаются пропущенными
   - После подтверждения кнопка заменяется на `✅ Готово` (неактивна) — повторное подтверждение невозможно
   - Механизм: `HostJobs` (фоновый worker) проверяет каждую минуту пользователей с установленным временем

6. **REST API:**
   - `POST /api/v1/habits/{id}/log` — тело: `{ "date": "2026-06-13", "isCompleted": true }`
   - `GET /api/v1/habits/{id}/stats` — возвращает streak, monthly, calendar
   - Идентификация: `X-Telegram-Id` header

### Нефункциональные

- Streak вычисляется на лету (из `HabitLog`), не хранится отдельно
- Лимита на количество привычек у пользователя нет
- API и Telegram используют общий Application-слой (`IHabitService`)
- Отметка через Telegram и API сохраняется в одну таблицу `HabitLog`

## Валидация и граничные случаи

- **Дата в будущем:** `POST /api/v1/habits/{id}/log` с датой > сегодня → 400 BadRequest
- **Привычка не найдена / не принадлежит пользователю:** 404
- **Дублирование отметки:** если `HabitLog` за дату уже существует — обновить `IsCompleted` (upsert), не создавать дубликат
- **Пустая дата / невалидный формат:** 400
- **Streak при перерыве:** если сегодня нет отметки — streak = 0
- **Streak не начинается с сегодня:** streak считается от последней последовательной даты с отметкой
- **Нет ни одной отметки:** streak = 0, monthly = 0%
- **Пользователь не зарегистрирован:** 404 при запросе через API
- **Нет вечернего времени:** напоминание не отправляется (тихо)
- **Нет привычек на сегодня:** напоминание не отправляется (или отправляется "Все привычки отмечены ✅")
- **Напоминание отправлено, но пользователь не нажал кнопку:** не переотправлять (просто не слать повторно в тот же день)
- **Некорректный формат даты при ручном вводе:** сообщить об ошибке, попросить ввести снова (не сбрасывать `PendingAction`)

   - Расширить `HabitsCallbackHandler` новыми case
